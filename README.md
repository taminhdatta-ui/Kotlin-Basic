# 🚀 Cách chạy

## 1. 💻 Yêu cầu môi trường

Trước khi chạy project, bạn cần cài đặt:

1. Git
2. Java JDK
3. Visual Studio Code
4. Gradle
5. Kotlin Compiler

### 🔹 B1: Tải và cấu hình môi trường chạy Kotlin trên VSCode

**How to Run Kotlin Program in Visual Studio Code | Install and Setup Kotlin in VS Code Tutorial**

🔗 https://www.youtube.com/watch?v=AbjdtTYca64

> ⚠️ Nếu sau B1 của bạn bị **FAIL** thì tiếp tục follow B2.

### 🔹 B2: Cài đặt Gradle

Truy cập:

🔗 https://gradle.org/releases/#9.7.1

- Click vào **Binary-only** (phiên bản mới nhất).
- Edit **Environment Variables**.

## 2. 📥 Cách tải dự án về máy local để chạy

### 🔹 B1: Copy đường dẫn

```text
https://github.com/taminhdatta-ui/Kotlin-Basic.git
```

### 🔹 B2: Mở Git Bash

Mở **Git Bash**, sau đó chạy:

```bash
git clone https://github.com/taminhdatta-ui/Kotlin-Basic.git
```

Sau khi tải project thành công, mở project bằng **VSCode**.

### 🔹 B3: Chọn chương trình muốn chạy

Click vào chương trình bạn muốn chọn và chạy nó trên **VSCode**.
